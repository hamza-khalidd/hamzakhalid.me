Things I had to write down.

Short notes on agents, retrieval, models and data. Each one comes with a picture that moves, so the idea is easier to see than to read.

01 Agents Agentic loop An agent is a loop with a stop. It holds a goal, takes one step, checks what came back, and goes again until the goal is met. read 02 Agents Orchestration One coordinator holds the brief and hands pieces to specialist agents. They work in parallel, report back, and the coordinator stitches one answer. read 03 Data Text to SQL A plain question becomes a query against a real table. The database runs it, and the answer is rows you can check, not a guess. read 04 Models How an LLM writes The model never fetches a finished sentence. It scores every possible next token, picks one, appends it, and starts again. read 05 Search Embeddings Words and passages become points in space. Things used in similar ways land close together, so distance can stand in for meaning. read 06 Search Retrieval (RAG) Before answering, the system searches your documents, keeps the best few chunks, and puts them in the prompt so the model answers from them. read 07 Search Chunking Long documents are cut into overlapping pieces before they are embedded. The cut decides what can be found later. read 08 Agents Tool calling The model does not run anything. It writes a structured request, your code executes it, and the result comes back for the model to explain. read 09 Models Context window A model reads through a fixed-size window. When new tokens arrive, the oldest fall out, and anything outside the window is simply not there. read 10 Models Temperature One setting reshapes the model's next-token scores. Low temperature makes it repeat its top pick; high temperature spreads the choices out. read 11 Quality Evals A fixed set of questions with known answers, run every time something changes. It turns 'seems better' into a score, and catches what got worse. read 12 Quality Guardrails Checks before and after the model. One decides what the model may see; the other decides what a person may read. read
